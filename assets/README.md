# Application Icons

Place your application icons in this directory:

- **icon.png** - Linux icon (512x512 recommended)
- **icon.icns** - macOS icon
- **icon.ico** - Windows icon

You can use tools like:
- https://cloudconvert.com/png-to-icns (PNG to ICNS for macOS)
- https://cloudconvert.com/png-to-ico (PNG to ICO for Windows)

Or use command-line tools:
- `png2icns` for macOS icons
- `convert` (ImageMagick) for ICO files
